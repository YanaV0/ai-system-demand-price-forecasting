\*\*Компонент:\*\* `app.services.forecast`



\*\*Назначение:\*\* Принимает запрос на прогноз спроса на 7–30 дней и рекомендованную цену по одному товару, вызывает модель инференса, применяет прикладные правила и формирует готовый результат. Компонент отвечает только за прикладную логику и не зависит от FastAPI или базы данных.



\*\*Источник входных данных:\*\* Проверенный запрос из app.api.schemas и история продаж из app.storage.dwh.



\*\*Поля и диапазоны:\*\*



| Поле          | Тип           | Диапазон                                        |

|---------------|---------------|-------------------------------------------------|

| sku\_id        | строка        | 1–50 символов                                   |

| horizon\_days  | целое число   | от 7 до 30                                      |

| current\_price | число         | больше 0 и не больше 1 000 000                  |

| history       | список чисел  | не менее 14 значений, каждое не меньше 0        |

| promo         | bool          | True или False                                  |



\*\*Интеллектуальный механизм:\*\*



Используется готовая модель `LinearRegression` из `scikit-learn`, обученная заранее в `app.ml.inference`.



Что делает модель:

\- принимает признаки товара (цена, продажи, день недели, акция);

\- возвращает два числа: прогноз спроса и рекомендованную цену.



Что модель не делает:

\- не оценивает уверенность;

\- не проверяет адекватность прогноза;

\- не принимает бизнес-решений.



\*\*Прикладные правила:\*\*



1\. Спрос не может быть отрицательным; значение округляется.

2\. Рекомендованная цена должна лежать в приемлемом диапазоне (не быть сильно завышенной или заниженной).

3\. Если модель недоступна — fallback: среднее значение продаж за последние 7 дней, stale = true.

4\. Если истории недостаточно — решение передаётся человеку.



\*\*Результат для вызывающего кода:\*\* Объект с полями: forecast\_demand, recommended\_price, model\_version, stale, needs\_human\_review.



\*\*Отказ или передача человеку:\*\* Неверный вход — явная ошибка валидации. Модель недоступна — fallback с пометкой stale = true, без ложной уверенности. История короче 14 дней — needs\_human\_review = true, числовой прогноз не выдумывается.
