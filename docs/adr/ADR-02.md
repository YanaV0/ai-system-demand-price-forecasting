### ADR-02: Стратегия хранения и версионирования моделей и артефактов



\- **Статус:** Принято (Accepted)

\- **Контекст:** Модель прогнозирования спроса обучается периодически (например, раз в месяц) на новых данных. Нужно:



\- хранить веса модели и артефакты предобработки;


- воспроизводимо загружать в сервис инференса;


- не раздувать Git-репозиторий.



\- **Рассмотренные альтернативы:**



1\. Хранить файлы моделей прямо в Git.


2. Хранить модели в отдельном хранилище (S3/MinIO), а в Git — только код и настройки.



\- **Решение:** Второй вариант.

\- **Обоснование:** Файлы моделей большие и часто меняются — Git для этого не подходит.

\- **Последствия:** Главные преимущества: репозиторий остаётся лёгким, просто откатиться на старую модель, но нужно настроить отдельное хранилище.
